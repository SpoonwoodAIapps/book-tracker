# Book Tracker

A reading list sorted by what you want to develop: areas in priority order, and the books for each in the order you'll read them. Time each reading with a timer you can pause, log the page you started and stopped on, and see how much you read each day, week and month against a time goal.

**Use it:** open the site on your phone, then Share → Add to Home Screen (iPhone) or ⋮ → Add to Home screen (Android). It opens like an app and works offline.

**Your data:** everything you add is saved on the device you add it on. Nothing is sent anywhere. This repository only holds the app's code.

**Backups:** Settings → Download a backup. Restore it on any device with Settings → Restore from a backup.
